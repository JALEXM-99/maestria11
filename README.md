# Cargar Función 

Mediante el paquete **remotes** instalar la función que se encuentra en el repositorio de Git-Hub

---
# Descripción de la función
Esta función permite detectar y corregir los valores atípicos de un conjunto de datos almacenados como vector. La corrección para este tipo de datos,
se lo realiza mediante la aplicación del método rango intercu rango intercuartílico (IQR).

---
# Ejecutar la función
Una vez instalado el paquete llamar a la librería **montoya1** donde se encuentra almacenada la función **detectar_filtrar_outliers**,
posterior a ellos dentro de los argumentos de la función colocar un conjunto de datos tipo vector.
